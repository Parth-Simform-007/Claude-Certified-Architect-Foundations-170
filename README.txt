CLAUDE ARCHITECT PRACTICE STUDIO

QUICK START
1. Extract the ZIP into a folder.
2. Double-click exam.html to open it in a modern browser.
3. Choose a batch, select answers, and click Finish batch to see your score.
No installation, internet connection, account, or server is needed.

FIVE BATCHES
Batch 1: Questions 1–34
Batch 2: Questions 35–68
Batch 3: Questions 69–102
Batch 4: Questions 103–136
Batch 5: Questions 137–170

RESULTS
Each correct answer earns one point; wrong and unanswered questions earn zero.
Answers are locked when submitted. The results show correct, wrong, and unanswered
question numbers. Click any number to review your answer, the PDF answer key, and
its explanation. Retake this batch clears only that batch after confirmation.

KEEPING YOUR PROGRESS
Every selection automatically saves in browser storage. Reopen the same file in
the same browser/profile to resume. Browser storage is not a permanent file backup:
clearing browser data, private mode, moving the HTML, or changing browsers may
remove or separate it.

For progress stored INSIDE an actual HTML file, click Save portable HTML. This
creates claude-exam-saved.html with your current progress embedded. Keep and reopen
that downloaded copy on any device. Save a new portable copy after later changes.
A browser cannot silently overwrite the original HTML file.

Backup downloads your progress as JSON. Restore imports it with confirmation.
All copies in the same browser storage context use the same progress key; the
newer saved progress takes precedence when reopening. Restore a JSON backup if
you intentionally want to return to an older attempt.

SOURCE
Questions and explanations extracted from your supplied PDF. The PDF contains
175 questions; this app includes only 1–170, as requested. Q140 has three choices
in the source, which are preserved. Text wrapping is normalized for readability.
The app follows the PDF's answer key without independently verifying its claims.
This is a practice tool, not an official exam or an official passing-score model.
